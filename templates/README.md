# Templates

Reusable starting points for real client projects, one folder per business type. A template is
a cleaned-up demo: same structure, but with clear placeholders (`{{BUSINESS_NAME}}`,
`{{PHONE}}`...) and a short `README.md` explaining what to change.

Templates are **not published** on the website — they are working material.

Same rules as demos: self-contained, relative paths, no external scripts or fonts, no real
personal data.
