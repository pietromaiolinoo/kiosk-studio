# Demos

Sample websites, one folder per business type. They show prospects what their site could look
like, and they are published at `/demos/<business-type>/`.

```
demos/
  florist/
    index.html
    css/
    images/
  cafe/
  barbershop/
  ...
```

Rules for demos:

- Use clearly **fictional** businesses (e.g. "Bloom & Stem Florist"), placeholder contact
  details (`hello@example.com`) and no fake reviews presented as real.
- Each folder is **self-contained**: its own CSS and images, no files shared with other folders.
- All paths are **relative**.
- Images must be our own, or free to use with the licence noted in the demo's folder.
