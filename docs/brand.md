# Brand notes

Working notes — to be refined while building the studio website.

## Personality

Modern, calm, trustworthy. A friendly local professional, not a tech agency.

## Voice

- Plain English, short sentences, no jargon.
- Honest and specific: what you get, what it costs, how long it takes.
- No hype, no invented numbers, no fake urgency.

## Look

Editorial and calm, like a small consultancy: big serif headlines, thin dividing lines,
plenty of space. Avoid the "template" look: no rounded cards everywhere, no gradients,
no pill badges, no icons in coloured squares.

## Colours

Predominantly blue and gray. Check every text/background pair for contrast (WCAG AA).

| Role             | Colour    |
|------------------|-----------|
| Navy (main dark) | `#0c2340` |
| Navy (sections)  | `#11304f` |
| Blue (buttons, logo blue) | `#0a54b5` |
| Light blue text  | `#c2d6ee` |
| Light blue bg    | `#dde8f5` |
| Gray bg          | `#e4e8ee` |
| Text             | `#1f2b3a` |
| Muted text       | `#4d5a6a` |

## Typography

- Headings: **Source Serif 4** (variable, light/regular weights at large sizes).
- Text and interface: **Source Sans 3**.
- Both are free (SIL Open Font License) and stored in `site/fonts/` with their licences.
  Never load fonts from Google Fonts or any other outside service.

## Logo

The logo is a "KS" mark (dark K, blue S) plus the words "Kiosk Studio".

| File (in `site/assets/`) | Use |
|--------------------------|-----|
| `logo.png`               | Original colours, for light backgrounds |
| `logo-light.png`         | White and light blue, for the dark blue header and dark images |
| `logo-mark.png`          | The "KS" mark alone, original colours |
| `favicon.png`, `apple-touch-icon.png` | Browser tab and phone home-screen icon (light mark on navy) |

Logo blue is about `#004fb3`; the site's button blue was aligned to it.
